# 模型问答

## 模型范围

模型问答页固定提供以下模型：

- `gpt-5.6-sol`
- `gpt-5.6-terra`（默认）

浏览器中已有的本地会话会在再次打开时迁移模型名：

- `gpt-5.5` 迁移为 `gpt-5.6-sol`
- `gpt-5.4` 和 `gpt-5.4-mini` 迁移为 `gpt-5.6-terra`

## 交互约束

- 流式回复期间锁定会话切换、API 地址、API Key、模型、深度思考和联网搜索，停止或完成后恢复，确保页面配置与当前请求一致。
- 深度思考关闭时发送 `medium`，开启时为 GPT-5.6 模型发送 `max`。
- 中文等输入法处于组合输入状态时，Enter 只完成输入，不发送消息；普通 Enter 发送，Shift+Enter 换行。
- 用户停止尚未返回任何内容的请求时，不保留空白助手消息；已经返回的部分内容继续保留。
- 用户停留在消息底部时自动跟随流式内容；用户向上阅读后停止自动滚动，并显示“回到最新消息”。

## 数据范围

会话、消息和当前 API Key 仍按现有设计保存在当前浏览器的本地存储中，不写入后端。清理浏览器站点数据会删除这些本地会话。
