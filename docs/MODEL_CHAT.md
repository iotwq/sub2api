# 模型问答

## 模型范围

输入 API 地址和 API Key 后，点击「同步模型」读取该接口的 `/v1/models` 列表，再选择模型开始对话。地址可填写站点根地址或带 `/v1` 的地址。

不再限制为两个固定模型，也不再改写旧会话的模型名。同步返回的 GPT、Claude、Grok 等模型 ID 均原样展示和发送。首次同步默认选择列表首项；再次同步保留仍然可用的选择，已被移除的模型改选首项。

更换 API 地址或密钥后清空旧列表，需要重新同步；切换到使用不同地址或密钥的本地会话时同样适用。空列表或同步失败会提示原因，不会生成固定的备用模型列表。重新打开已有配置的页面时自动同步一次。

## 交互约束

- 空白页提供解释代码、排查报错、编写脚本和分析文档入口，只预填草稿，点击不发请求。用户首次发送时自动创建会话；可以先添加附件，无需先手动新建。缺少连接配置或模型时显示相应引导。
- API 地址和 Key 放在可展开的「连接设置」中，首次未配置 Key 时展开；模型同步、选择及推理强度放在输入框附近。会话列表可收起，窄屏使用抽屉；专注模式铺满浏览器视口，可点击退出或按 Escape 返回。
- 问答模块在页面四周仅保留约 8px 留白，桌面会话栏宽 200px；回复和输入区域随可用宽度展开，超宽屏最多 1440px。压缩顶部工具栏、底部配置区及消息卡片留白，让回复区显示更多内容；这些尺寸只影响模型问答页面。
- 输入框从单行约 40px 高开始，随输入内容自动增高，清空或发送后收回；最高为 200px 或窗口高度的四分之一（取较小值），超出后在框内滚动。切换会话栏、专注模式或调整窗口时重新计算高度，保留 Shift+Enter 换行及中文输入法保护。
- 推理强度可选 `low`、`medium`、`high`、`xhigh`、`max`，默认 `medium`，随会话和草稿保存。旧会话未保存推理强度时使用 `medium`，不再读取旧的深度思考开关。
- 选择框左侧显示「推理强度」，鼠标悬停标签可查看用途、默认档位和耗时差异，读屏也能读取说明；窄屏下模型与推理强度分行显示。
- 移除联网搜索开关。Responses 模型默认发送 `tools: [{"type":"web_search"}]`、`reasoning.effort` 和 `store: false`；Claude、Grok、Gemini、Suno、图片和视频模型使用 Chat Completions，并省略 Responses 专用字段。
- 流式回复期间锁定会话切换、API 地址、API Key、模型和推理强度，停止或完成后恢复，确保页面配置与当前请求一致。
- 中文等输入法处于组合输入状态时，Enter 只完成输入，不发送消息；普通 Enter 发送，Shift+Enter 换行。
- 用户停止尚未返回任何内容的请求时，不保留空白助手消息；已经返回的部分内容继续保留。
- 用户停留在消息底部时自动跟随流式内容；用户向上阅读后停止自动滚动，并显示“回到最新消息”。

## 回复状态

用户问题可编辑后重新发送，助手回复可重新生成或手动重试。上述操作在原问题之前的历史基础上创建新会话分支，保留原会话；每次都是新的 API 请求，可能收费。失败后恢复问题及附件，用户在等待期间输入的新草稿不会被覆盖。

根据真实 Responses 事件展示等待、思考、联网搜索和输出状态，并显示耗时。思考摘要只显示上游返回的公开摘要；没有对应事件时不推测模型行为。完成、停止及失败状态随消息保存。流式连接结束却没有完成事件时保留已有文字并提示未完整结束，不自动重复发起收费请求。

当前回复的状态和耗时统一显示在助手消息内，不再在消息列表底部重复展示“模型正在思考”或“正在回答”等提示；等待回复时也使用消息内的状态提示。

## 接口兼容

API 地址需提供 OpenAI 兼容的模型列表，以及与所选模型对应的 `/v1/responses` 或 `/v1/chat/completions` 接口。页面按模型类型选择协议；直接连接其他 API 服务时，应同时提供所选模型需要的接口。

模型出现在列表中不代表它支持全部推理档位、联网搜索或图片输入；实际支持范围及推理等级转换由服务端和上游模型决定。页面不会在失败后擅自关闭搜索或重写模型 ID。

## 代码与来源

代码块提供常用语言语法高亮、横向滚动、展开查看、复制和下载；展开视图只显示代码文本，不执行 HTML 或脚本。下载使用 snippet 和语言后缀，不会写入用户项目。搜索来源仅展示上游返回的 HTTP(S) 链接，重复链接合并，打开新标签页时隔离窗口引用。

## 数据范围

流式正文最多每 50ms 合并一次显示；已完成的 Markdown 按消息缓存，代码高亮在回复结束后完成。本地流式保存最多每秒合并一次，完成、失败、停止、页面卸载和 pagehide 时立即刷新已收到的正文及状态。离开页面时中断未完成的回复并标记为已停止；用户向上阅读时不强制滚动。

会话和消息按现有设计保存在当前浏览器的本地存储中，不写入后端。API Key 只在当前页面内存中使用，不再写入浏览器存储；历史会话中的 API Key、附件 Data URL 和附件正文也会在保存时清除。清理浏览器站点数据会删除这些本地会话。
